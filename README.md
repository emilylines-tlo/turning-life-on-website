# Turning Life On — Website

The website files for [Turning Life On](https://www.turninglifeon.org), a
Massachusetts 501(c)(3) helping local leaders start and sustain grassroots
digital-wellness movements.

## What's in here

Seven pages, each a standalone HTML file:

| File | Page |
| --- | --- |
| `index.html` | Home |
| `about.html` | About Us |
| `take-action.html` | Take Action |
| `resources.html` | Resources |
| `network.html` | Network |
| `events.html` | Events |
| `support.html` | Support |

## Status

Work in progress. This is a refresh of the previous Squarespace site, with a
revised layout, updated content, and upcoming integration of community map,
events, and resource library data.

## Editing

Each file is plain HTML and can be opened in any browser to preview it. Styling
is currently written inside each page.
